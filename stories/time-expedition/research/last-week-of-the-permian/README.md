# The Last Week of the Permian Research

This directory separates external research, project review, and approved
canonical guidance.

| Artifact | Role | Status |
|---|---|---|
| `pro-research-prompt.md` | Prompt used to commission the external report | Retained provenance |
| `the-last-week-of-the-permian-dual-layer-research-dossier.md` | Full Pro research output | External input; unchanged |
| `research-input-review.md` | Bounded source and confidence audit | Accepted correction ledger |
| `canonical-research-dossier.md` | Compact project distillation | Approved project reference |

The external report is not canonical merely because it is detailed. Project
work follows the approved canonical dossier, whose evidence bounds and
research stop rule control subsequent architecture and drafting.

No manuscript prose, detailed chapter architecture, or scene cards should be
derived directly from the external report without passing through the review
and canonical distillation layers.
