# Forensic Source Study

This directory stores source-study evidence and method, never manuscript prose.

`admission.yml` is the exact corpus gate. `original/sources.yml` contains only
retained, admitted artifacts. Approved sources may be acquired; proposed
sources may not.

The generated review surface is
`build/time-expedition/reports/source-admission-report.md`. Detailed analysis
is blocked until the human approves that report.
