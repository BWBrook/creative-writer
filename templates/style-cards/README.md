# Style Cards

This directory holds reusable style-card templates for story scaffolding.

Each card should be:

- author-neutral in naming, even when clearly inspired by a recognisable tradition
- written for adult prose, not flattened into contemporary workshop-safe blandness
- descriptive of cadence, diction, structure, motifs, and moral weather
- useful both as a writer's briefing and as a prompt seed for an AI collaborator

## Recommended Structure

Use this section order where practical:

1. `# Style Card: <Name>`
2. `## Core Idea`
3. `## Voice & POV`
4. `## Tone`
5. `## Pacing & Structure`
6. `## World-Building` or `## Setting / World Detail`
7. `## Characters`
8. `## Dialogue`
9. `## Diction & Syntax`
10. A style-specific craft section where needed
11. `## Motifs`
12. `## Moral Stance`
13. `## Common Pitfalls To Avoid`
14. `## Ready-to-Paste Prompt`
15. `## Fill Slots`
16. `## Micro-Techniques`
17. `## Self-Audit Checklist`

Not every card needs every section, but the shape should stay broadly familiar.

## House Conventions

- Use Markdown headings, not plain labels.
- Use normal Markdown bullets (`-`), not tab-indented typographic bullets.
- Use `---` as the section break before prompt-oriented material.
- Prefer British spelling unless the style itself clearly demands another register.
- Keep example phrases short and reusable.
- Preserve historical or genre-specific texture where it matters.
- Avoid forcing present-day sensibilities onto older prose traditions unless the card is explicitly contemporary.

## Naming

- Filenames should be lowercase with underscores.
- Keep names descriptive of the style family rather than the source author.
- Example: `weather_and_work_adventure_thriller.md`

## Intent

These cards are not meant to imprison a story. They are starting pressures:

- a default voice
- a default moral atmosphere
- a default sentence gait
- a default sense of what belongs on the page and what does not

Story-specific adaptation should still happen later in each story's
`style-guide.md`.
